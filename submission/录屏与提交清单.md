# 两分钟录屏脚本

建议录屏时不要展示任何真实 API Key；直接使用离线演示即可证明 Agent 闭环真实执行了 pytest。

- `0:00–0:12`：展示仓库首页，说明这是不用 Agent 框架、面向小型 Python 项目的测试驱动修复 Agent。
- `0:12–0:30`：快速展示 `src/testpilot/`，口头说明七个工具、模型循环、固定验证门和 JSONL 轨迹均为自行实现。
- `0:30–1:15`：在终端运行 `python -m testpilot.demo`。解释 `BEFORE=FAIL` 是原始测试失败，`AGENT=SUCCESS` 是 Agent 修改并申请验证，`AFTER=PASS` 是宿主再次运行真实 pytest 后通过。
- `1:15–1:38`：运行 `python -m pytest -q`，展示完整自动化测试结果。
- `1:38–1:52`：展示 README 的安全边界：工作区限制、tests/配置/显式验证目标/trace 保护、pytest 参数限制、敏感环境变量过滤。
- `1:52–2:00`：总结“模型只能建议工具调用，成功由本地固定验证决定”。
